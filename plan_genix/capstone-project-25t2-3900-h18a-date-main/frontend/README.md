# PlanGenix – Frontend (Vite + React)

This is the frontend for **myPlan++**, a UNSW course planning web application. Built using [Vite](https://vitejs.dev/) and [React](https://react.dev/), the interface allows students to upload their transcript or manually enter courses, view their study plan, and make custom edits to their degree or stream.

---

## Getting Started

### Prerequisites

- Node.js (v20 or later)
- npm (v9 or later) or yarn

### Install dependencies

npm install

### Start the development server

npm run dev

Visit: http://localhost:5173

### Tech Stack

- Framework: Vite + React
- Routing: React Router
- UI Library: Material UI (MUI)

### Scripts

| Command           | Description                      |
| ----------------- | -------------------------------- |
| `npm run dev`     | Start development server         |
| `npm run build`   | Build for production             |
| `npm run preview` | Preview production build locally |
